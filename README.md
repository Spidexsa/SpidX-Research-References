# 🕸️ SpidX: Smart Robotic Swarm System - References & Documentation

Welcome to the official references repository for **SpidX** (Crisis Spiders), a bio-inspired robotic swarm integrated with Digital Twin technology for infrastructure inspection, heritage preservation, and hazard assessment.

## Academic & Literature References
